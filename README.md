# 🚀 TRAPPIST Messenger

**TRAPPIST** — децентрализованный мессенджер нового поколения, созданный для людей. Настоящая безопасность, честная приватность и полная автономность без центральных серверов и скрытого сбора данных.

🌐 **Веб-версия (запуск в браузере):** [https://github.io](https://github.io)

---

## 🛡️ Почему выбирают TRAPPIST?

* **Прямая связь без серверов (P2P).** Сообщения передаются напрямую от устройства к устройству по защищённому каналу WebRTC. Ваши диалоги не проходят через сторонние базы данных и нигде не логируются.
* **Изолированные профили.** Для каждого никнейма и пароля создаётся собственное независимое локальное хранилище прямо в памяти вашего устройства.
* **Ничего лишнего.** Лёгкий, быстрый и тёмный интерфейс в стиле современных мессенджеров — всё сделано для того, чтобы ваши сообщения доходили мгновенно и без сбоев.
* **Кроссплатформенность.** Работает как полноценное Android-приложение (APK), так и в любом современном браузере на ПК и смартфонах.

---

## 📡 Как подключиться к собеседнику (P2P)

Поскольку у **TRAPPIST** нет центрального сервера, установка прямого туннеля происходит через быстрое ручное рукопожатие:

1. Откройте любой чат и нажмите кнопку **«📡 P2P связь»**.
2. Нажмите **«1. Создать код моего узла»** и скопируйте появившийся текст.
3. Отправьте этот код собеседнику.
4. Собеседник вставляет ваш код во второе поле, нажимает **«Подключиться»** и отправляет вам свой ответный код.
5. Вставьте ответный код собеседника в своё второе поле и нажмите **«Подключиться»** — статус сменится на **`● P2P узел активен`**.

## 🛠️ Технологии

* **Frontend:** HTML5, CSS3 (адаптивная вёрстка под Android и Desktop), Vanilla JavaScript (ES5/ES6).
* **Сеть:** WebRTC DataChannel + публичные STUN-серверы для обхода NAT.
* **Хранилище:** Изолированный LocalStorage с резервным буфером памяти.
